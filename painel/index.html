DO PAINEL PARA A IDE
Um .ino pronto para carregar.
Escolha a base original ou gere um arquivo com os valores do formulário. O download prepara o código; o envio à placa é feito na IDE Arduino.
↓ Baixar .ino padrão
  1. 01Abra o arquivo na IDE Arduino e aceite criar a pasta ControleTrafego, se solicitado.
  2. 02Selecione Arduino Uno, a porta USB e clique em Carregar →. Desconecte o painel para liberar a porta.
  3. 03Feche o Monitor Serial e reconecte o painel para conferir os tempos recebidos.
O que acontece com os tempos salvos?
Se o PADRAO do arquivo mudar, as configurações salvas de outro perfil serão ignoradas. Se enviar novamente o mesmo perfil, os ajustes salvos para ele continuam valendo. Use “Restaurar e salvar padrão” para voltar ao padrão original do projeto sem editar o código. A primeira carga desta atualização ignora a EEPROM da versão anterior.

Roteiro para repetir a demonstração
  1. Restaure o padrão e confira o ciclo de 26 s.
  2. Mostre A verde → amarelo → intervalo → B verde.
  3. Na área interativa, reproduza prioridade e conflito. Use congelar e avançar fase para explicar.
  4. Mude os tempos, aplique e demonstre que a fase atual não é encurtada.
  5. Restaure o padrão novamente para preparar a próxima apresentação.
  6. Na placa, teste os botões e LEDs e registre o resultado do ensaio físico.

    Não conectada
    Uno compatível com CH340 pode aparecer como USB Serial ou Unknown. Selecione essa porta. Para controlar pelo painel, carregue a versão USB do .ino, a 115200 baud.
    Ver pinagem e instruções ↗
    Via A: verde D2, amarelo D4, vermelho D7.
    Via B: vermelho D3, verde D6, azul D5.
    Pedestres: D9 (A), D8 (B).
    Botões: D11 (A), D12 (B), ligados ao GND com INPUT_PULLUP.
    Carregue o .ino na IDE Arduino. Feche o Monitor Serial e clique em Conectar Arduino. Use Chrome ou Edge no computador em localhost.
    Se a porta estiver ocupada, o Fluxo tenta transferir a conexão da outra aba do próprio painel. O Python também pode liberar apenas o processo do Monitor Serial da IDE, quando identificado com segurança. Não fecha Chrome nem o editor; se a identificação não for possível, feche o Monitor Serial/Plotter manualmente.
    Os LEDs de pedestres seguem a lógica do projeto original. O desenho é ilustrativo; não representa a montagem elétrica.
